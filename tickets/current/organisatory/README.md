# Current organisatory records

Place an active development ticket here when its main implementation changes contributor workflow, repository or document structure, shared conventions, or cross-cutting consolidation. Place a coordination record here when it groups cross-cutting peer development tickets without implementing their work. Use the distinct headings and templates described in the [root work-record guide](../../README.md).

See the [root work-record index](../../README.md) for status, relationships and archived work.
